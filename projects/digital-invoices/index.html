Python · SOAP · XML / XSD · XMLDSig

Схема иллюстрирует тип решения. Это демонстрационные данные, не снимок рабочей системы заказчика. Описание обезличено.

Задача

Для обмена документами нужна связка структурированных данных, схем XML и электронной подписи.

Что собрано

Разработали клиент SOAP API, построение XML по схемам и адаптер локального подписанта.

Что это даёт

Подготовлен прототип интеграции для тестового контура. Продуктивный запуск и проверка полного обмена остаются отдельным этапом.

  • XML по схемам
  • Электронная подпись
  • API документов
