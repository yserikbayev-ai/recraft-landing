# CLAUDE.md — ReFactor (лендинг RECRAFT)

## Что это за папка

Кодовый проект (статический сайт). Одностраничный лендинг консалтинговой компании **RECRAFT** — «операционная трансформация бизнеса» (внедрение CRM/ERP, AI-автоматизация, антикризисный менеджмент). Это git-репозиторий, подготовленный под публикацию на GitHub Pages.

От Claude здесь обычно требуется: правки вёрстки/контента/стилей, доработка анимаций и адаптива, помощь с деплоем на GitHub Pages.

> README.md в папке уже есть — он первичный источник по проекту. Не переписывать его.

## Технологии / стек

- Чистый HTML / CSS / JS, без фреймворков и сборщиков.
- Один файл `index.html` (включает стили и скрипты).
- Google Fonts: DM Sans + Space Mono.
- Тёмная тема, PDCA-брендинг, scroll-reveal анимации, мобильная адаптивность.
- Деплой: GitHub Pages (Settings → Pages → main / root).
