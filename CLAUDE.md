# CLAUDE.md — REFACTOR (лендинг, refactor.kz)

## Что это за папка

Кодовый проект (статический сайт). Одностраничный лендинг консалтингового бренда **REFACTOR** — финансовый контроль и цифровой порядок для промышленных компаний Казахстана (управленческая отчётность, закупки, учётные системы, AI поверх 1С). Прежнее имя бренда RECRAFT выведено из обращения — в текстах не использовать; бэкап прежней версии лежит в `index.html.bak-recraft`. Это git-репозиторий; действующий домен обслуживается Caddy на финском сервере, GitHub Pages сохраняется как копия.

От Claude здесь обычно требуется: правки вёрстки/контента/стилей, доработка анимаций и адаптива, помощь с деплоем на GitHub Pages.

> README.md в папке уже есть — он первичный источник по проекту. Не переписывать его.

## Технологии / стек

- Чистый HTML / CSS / JS, без фреймворков и сборщиков.
- Один файл `index.html` (включает стили и скрипты).
- Дизайн «Midnight Executive» (navy/gold/terracotta), светлая + тёмная темы, системные шрифты (без CDN), scroll-reveal, мобильная адаптивность.
- Деплой домена: Caddy на `claude-server`, каталог `/opt/recraft-landing` → `/srv`. GitHub Pages (`main` / root) — копия; push не обновляет действующий домен.
