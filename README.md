# REFACTOR — портфолио цифровых систем

Одностраничный сайт консалтингового бренда **REFACTOR** (ИП «Серикбаев Е.О.», Астана):
финансовый контроль и цифровой порядок для строительных, горнодобывающих, телеком-
и транспортных компаний Казахстана.

**Живой адрес:** https://refactor.kz

## О проекте

- Основной сайт с 16.09.2026: «Сложный бизнес. Ясная система».
- Статические HTML/CSS/JS: `index.html`, `styles.css`, `app.js`, без фреймворков.
- Локальные шрифты Onest, оригинальная иллюстрация, адаптивность и reduced-motion.
- 35 обезличенных проектов, шесть визуальных кейсов, поиск и фильтры.
- Трёхшаговый бриф с копированием, скачиванием и переходом в WhatsApp.

## Структура страницы

Главный экран → направления работы → визуальные кейсы → каталог → AI-практика →
подход → основатель → FAQ → бриф и контакты.

## Деплой

Действующий домен `refactor.kz` обслуживает Caddy на финском сервере (`claude-server`), каталог `/opt/recraft-landing`, смонтированный в контейнер как `/srv`. GitHub Pages (`main` / root) продолжает собираться как копия, но push в GitHub сам по себе не обновляет этот домен.

Публичные файлы находятся непосредственно в корне: `index.html`, `styles.css`,
`app.js`, `projects.json`, `sitemap.xml`, каталоги `assets/` и `projects/`.
Загружайте их в staging вне web-root, затем публикуйте зависимости и заменяйте главную
страницу последней. На сервере в этом каталоге также находятся другие приложения:
**не применять rsync --delete к корню и не заменять его целиком**.

Каталог `/v2/` удалён. Caddy перенаправляет старые ссылки `/v2/…` на соответствующие
адреса без префикса. Резервная копия предыдущей главной и версии V2 хранится вне web-root.

## Исходники и обновление (16.09.2026)

Портфолио опубликовано как основной сайт: [refactor.kz](https://refactor.kz/).

- `index.html`, `styles.css`, `app.js` — страница и интерактивность.
- `projects.json` — обезличенные кейсы, статусы и описания; `projects/` — статические страницы.

- `ASSUMPTIONS.md` — решения по дизайну, публикации и обезличиванию.
